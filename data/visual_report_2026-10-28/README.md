# Rover visual report

Open [report.html](report.html) in a browser. It is a self-contained offline file:
the video preview, camera frames, plots and audited inventories are embedded.

- **Runs:** select the contest-linked main recording, related drives, recovered
  October 24 excerpt, or Scout jump windows. Metrics link to their source files.
- **Video:** play received frames, inspect the contact sheet, and compare playback
  time with the original elapsed-time coverage and gaps.
- **Files:** search all 327 indexed vehicle files by path or role; select a
  filename for its host, dependencies and original-file link.
- **Resume:** view the software/device relationships and the preserved guides.

The operator identified the displayed arena footage as the actual October 24
contest. Video metadata links it to `e2c0c0d3`; the approximate 15-minute duration
is an operator recollection. The main CSV spans 9:20 and the related short CSV
7:28, but they are not joined into a proven continuous 16:48 run. Earlier
practice/date labels and invalid 1970 clock values remain unchanged in originals.
The newer `684775d5` excerpt was separately recovered byte-for-byte; it is not
automatically assigned to the contest. See [the clarification](operator_clarification.json)
and [recovery receipt](recovery_receipt.json).

This is the finished report. Its data, plots and video preview are embedded in
the HTML; no report builder, external media input or server is needed.

The inventory excludes this report's own files and ignored credentials/private
firmware. Source-file links work when the report remains in this repository.
Original recording bytes were not rewritten. The file index reflects the
core-only cleanup; the operational handbook is indexed in `docs/README.md`.
