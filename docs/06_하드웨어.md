# 모터·Pico 연결 참고

실행은 [README](../README.md), 실제 보드 pinout은 [PCB 원본](electronics/PDB_Design_Handover.md).
숫자 설정의 원본은 [config.py](../rover/config.py); 아래는 점검 순서다.

| 장치 | 확인 |
|---|---|
| U2D2 | `/dev/u2d2`, 중복 실행 없음, 모터 공통 baud와 `BAUDRATE` 일치 |
| 바퀴 | `WHEELS`의 ID/좌우/부호 일치. 현재 ID 1–4, 4.5 Mbps |
| 모터 운전 | Velocity mode. 실제 설정·동작은 조립 후 확인 |
| Pico | `/dev/pico`, [main.py](../firmware/pico/main.py), MicroPython |
| 서보·INA226 | `SERVOS` trim/방향, 실제 shunt·배터리 측정 확인 |

모터의 reverse 설정과 소프트웨어 부호를 동시에 뒤집지 않는다.
[vendored SDK](../rover/vendor/PATCHES.md)는 4.5 Mbps 지원 수정이 있으므로 임의 교체하지 않는다.
읽기 실패·프로세스 정지 때 실제로 멈추는지 [SAFE-01](05_한계와_로드맵.md#safe-01) 검증이 필요하다.

Pico 펌웨어 복사 명령은 README에 있다. 서보 중립·방향·부하, USB 단절 watchdog,
INA226 표시를 실제 하드웨어에서 확인한 뒤 사용한다. 현재 pan 회전 제한과 배터리
경고 값은 완성된 보호 기능으로 간주하지 않는다 ([IO-01](05_한계와_로드맵.md#io-01)).
무부하 모터 사양이나 전류만으로 실차 속도·거리·슬립을 확정하지 않는다.
