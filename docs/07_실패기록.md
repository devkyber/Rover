# 반복하지 말아야 할 문제

전체 34개 기록과 당시 근거는 [원문 아카이브](archive/README.md).
현장에서 다시 만날 가능성이 큰 항목만 남긴다.

<a id="f-09"></a>
### F-09 — 읽기 실패가 정지를 건너뛰는 경로
통신 실패 뒤에도 모든 모터에 정지를 시도해야 한다. 프로세스 freeze/kill과 bus 단절까지
포함한 하드웨어 watchdog 검증은 [SAFE-01](05_한계와_로드맵.md#safe-01)에 남아 있다.

<a id="f-15"></a>
### F-15 — SDK에 4.5 Mbps가 없음
현재 [SDK 수정](../rover/vendor/PATCHES.md)을 유지한다. SDK 업데이트 때 해당 지원을 확인한다.

<a id="f-22"></a>
### F-22 — 공중 회전 기록으로 주행 튜닝
공중 바퀴 속도는 차량 이동 정답이 아니다. 해당 로그는 부호·버스 확인에만 쓴다.

<a id="f-32"></a>
### F-32 — 센서축과 body축 혼동
구형 Arduino CSV는 `logger.replay()`가 변환한다. 이미 body인 로그에 중복 변환하지 않는다.
BMI088는 별도 장착 map을 사용하며 장착 후 +g/회전 부호를 확인한다.

<a id="f-34"></a>
### F-34 — BMI088 P1/P2를 반대로 안내
P1=7핀 전원/인터럽트, P2=9핀 SPI. [기록된 핀맵](11_jetson_bringup.md)과
실물 라벨·pin 1을 함께 확인한다. 반복 ID 실패는 현재도 미해결이며 소프트웨어 통과로 숨기지 않는다.

## 통신 운용에서 확인한 것

노트북은 공유기 WAN이 아닌 LAN에 연결한다. 고정 주소는 DHCP 할당 범위에서 뺀다.
오래된 집 Wi-Fi 주소 대신 `.200`을 쓴다. Wi-Fi 절전을 끄고, USB NCM 오류가 있었으므로
USB SSH만을 복구 계획으로 삼지 않는다. [통신 기록](12_field_link.md).
