# 참고 이력 보관

[references_2026-10-08.zip](references_2026-10-08.zip)은 정리 전 문서·검토·제안서·실험 보고서의
원문이다. ZIP 내부 `SHA256.json`으로 각 파일을 검증했다. 암호 파일은 제외했다.
현재 지침은 [문서 목차](../README.md), 현장 명령은 [README](../../README.md)를 따른다.

- 옛 이론·코드 설명·학습 노트·구매 결정의 근거를 찾을 때만 펼친다.
- 원문의 경로는 당시 저장소 기준이다. 일부 그림·이전 아카이브는 정리 전부터 없었으며
  이 ZIP이 누락 파일까지 복구한 것은 아니다.
- 옛 PCB/BOM과 제안서는 현재 회로·구현 상태를 증명하지 않는다.
- [실험 보관](../../data/archive/README.md)에는 분석 출력과 당시 남아 있던 소스가 있다.
- 저장소 밖 전체 백업도 유지했지만, 여기 안내한 데이터·문서 사용에 그 백업은 필요 없다.
