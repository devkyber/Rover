# 현재 동작 범위

현재 차량을 사용할 때 명령·센서값·추정값을 어떻게 읽는지 정리한다.
추가 개발이나 검증 과제 목록은 두지 않는다. 기존 파일명과 링크 anchor는 과거 참조를 위해 유지한다.
자세한 동작은 아래 연결된 문서가 설명한다.

## 명령·측정·추정 구분

| 구분 | 예 | 의미 |
|---|---|---|
| 명령 | 속도 요청, PWM, `LAUNCH` | 프로그램이 장치에 요청한 동작 |
| 응답·측정 | ACK, encoder, raw acceleration | 장치가 수락하거나 읽어 보낸 값 |
| 추정·등록 | ESKF 자세, wheel 경로, 지도 좌표 | 측정과 모델 또는 입력한 기준점으로 계산한 값 |
| 현장 관측 | 실제 이동·점프 label, 측량 위치, 영상 사건 | 원본과 함께 기록한 실물 관측 |

이 값들은 서로 연결되지만 같은 뜻은 아니다. 예를 들어 encoder 변화는 축 회전이고,
Rover 경로는 그 회전을 자세로 회전·적분한 값이다. 지도 등록은 이 경로의 좌표계를 바꾼다.

## 제어와 화면

| 기능 | 현재 동작의 의미 | 자세히 |
|---|---|---|
| 주행·중단 | 입력 만료·E-STOP·재접속 처리 경로가 있으며 재개에는 새 입력을 사용한다. 소프트웨어 중단과 구동 전원 차단은 별개다 | [운전 안내](../README.md#주행화면) |
| 실린더 | jog 후 버튼 해제는 torque ON HOLD. 표시 기준은 기계적 끝단 스위치가 아니다 | [하드웨어](06_하드웨어.md#clegg-설정과-시험) |
| STRING | 누름 유지 또는 시간 PWM 동작. 시간 완료는 위치 feedback이 아니다 | [하드웨어](06_하드웨어.md#clegg-설정과-시험) |
| PAN | 누르는 동안 회전. `SET 0`·누적 시간은 명령 기준이며 각도 센서는 없다 | [PAN](06_하드웨어.md#카메라-pan) |
| 배터리 | 전압·전류·전력과 저전압 안내. 개별 셀 보호·모터 잠금·전원 차단을 수행하지 않는다 | [하드웨어](06_하드웨어.md#모터pico) |
| dashboard | 기존 단일 화면에서 조종·표시. `READY`는 바퀴 정지 표시다 | [운전 안내](../README.md) |

## 자세와 이동

BMI088와 wheel 관측으로 자세·이동을 계산한다. 공개 위치는 ESKF 내부 관성항법 위치와 별도로,
자세로 회전한 wheel 전진속도를 적분한다. 시작 yaw=0은 local 기준이며 절대 북쪽이 아니다.
현재 입력에는 외부 절대 heading·위치 관측이 없다.

거리 profile은 geometry·부호·출처가 맞는 경우 선택해서 사용한다. 기본 설정은 profile을 선택하지 않은 상태다.
IMU가 끊긴 동안의 운동을 재접속 후 자동 복원하지 않는다. 표본의 시각·품질·run/frame/generation을 함께 해석한다.
식·가정·계산 예제는 [이론 문서](01_이론_오도메트리와_ESKF.md), 기록 필드는 [데이터 계약](13_scout_integration.md)에 있다.

과거 주행의 줄자 종방향 거리나 약 90° 라벨은 해당 관측 내용으로 보존한다.
연속 XY·heading 정답과 같은 의미로 확장하지 않는다. 당시 geometry·센서 encoding·설정도 현재 구성과 구분한다.

## Scout·Clegg·지도

| 대상 | 현재 제공하는 정보 | 해석 |
|---|---|---|
| Scout | 명령 응답, encoder, 센서 원본, 저장 결과 표시 | 명령 수락·encoder 변화와 실제 점프·접촉·정지 위치를 구분 |
| Clegg | 무선 raw count·nominal g·파형·후보 사건 | nominal g나 peak를 보정된 CIV/CBR로 자동 변환하지 않음 |
| Rover context | 시각·frame 조건이 맞는 Rover 기준 위치 | 실제 해머 접촉점과는 다른 기준점 |
| MISSION MAP | rigid XY 등록, 사건·정정 journal | 회전·평행이동은 경로 drift를 수정하지 않으며 fit residual은 위치 정확도가 아님 |

모르는 위치와 시각은 `Unknown`으로 기록한다. 사건 종류·시각·좌표·근거를 구분하는 방법은
[데이터·임무 계약](13_scout_integration.md)에 있다.

## 연결·기록·설치 이력

Field service는 SSH 연결과 별개로 실행되고, 브라우저·Wi-Fi에는 재연결 경로가 있다.
환경·AX210 kernel module·복구 명령은 [설치 안내](11_jetson_bringup.md)가 설명한다.

세션·IMU·영상·Scout raw·Clegg raw는 각각 기록 수명이 다르다. 영상은 H.264 TS 조각과 frame journal을 남기고
누락·오류를 표시한다. 저장 위치와 종료 상태는 [데이터 계약](13_scout_integration.md)을 따른다.

2026-10-28 인계 receipt와 hash는 그 시점의 파일·설치 기록이다. 이후 문서 수정이나 현재 장치 실행 상태를 나타내지는 않는다.
보존된 실차 원본은 [logs](../logs/README.md), 당시 설치 식별은 [인계 기록](../data/final_vehicle_2026-10-28/README.md)에 있다.
