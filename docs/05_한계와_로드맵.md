# 보관 시점의 한계

2026-10-28 KST 개발 종료 기준. 기존 작업 ID는 인계용으로 유지하고 미검증 항목은 미완료로 동결한다.
보관·구현·설치는 실차 안전/정확도/임무 성공의 증명이 아니다. 재개 시 아래 남은 검증부터 판단한다.
파일·역사적 설치/백업·closure 배포 여부는 [최종 인계](../data/final_vehicle_2026-10-28/README.md),
실차 원본은 [logs](../logs/README.md), 설정과 계산은 현재 소스가 원본이다.

<a id="safe-01"></a>
**SAFE-01 — 모터 오류·watchdog.**
시작 목표 0/readback·오류 시 정리 경로는 있으나 freeze/kill·전원/bus 단절의 실제 정지·재개 보장은 미검증이다.

<a id="safe-02"></a>
**SAFE-02 — E-STOP·입력 만료.**
만료·재접속 뒤 입력 미재생과 전역 중단 경로를 유지한다. 최종 실물의 실제 출력 정지·새 입력 복귀는 미검증이다.

<a id="hw-01"></a>
**HW-01 — 완성 구성·하중.**
설계·설치는 조립/하중 검증이 아니다. 실제 배선·축·전원·기구·중단/복구를 최종 구성에서 확인해야 한다.

<a id="io-01"></a>
**IO-01 — PAN·배터리.**
PAN은 명령 참고값이며 실제 각도/자동 끝단 제한이 없다. 배터리는 표시·경고만 하며 셀 보호/전원 차단은 없다.

<a id="ui-01"></a>
**UI-01 — 단일 dashboard.**
기존 주행 화면을 유지한다. 최종 노트북/모바일 입력·화면 잠금·단절 동작은 실물 확인이 필요하다.

<a id="odom-01"></a>
**ODOM-01 — 추정 입력·적분.**
공개 위치는 자세로 회전한 wheel 속도의 적분이다. 시각 pairing·실제 위치/각도 정확도는 독립 정답으로 검증해야 한다.

<a id="odom-02"></a>
**ODOM-02 — 장착·거리 보정.**
geometry/부호 검사를 갖춘 profile을 지원하지만 현재 차체 실측 profile은 없다. 축·bias·거리 보정과 tuning/검증 분리가 필요하다.

<a id="imu-01"></a>
**IMU-01 — BMI088 별도 추정.**
취득/복구/추정/저장을 제어와 분리했다. 반복 SPI ID 실패·지속 수신·실제 축/각도는 미검증이며 유실 운동을 복원하지 않는다.

<a id="odom-03"></a>
**ODOM-03 — 독립 주행 정답.**
과거 줄자 종방향 정지점과 약 90° 라벨은 연속 XY/heading 정답이 아니다. 최종 차체/센서의 독립 실측이 남아 있다.

<a id="est-01"></a>
**EST-01 — 추가 융합.**
현재 baseline을 유지한다. 새로운 외부 heading/위치 관측은 실제 오차·임무 예산을 측정한 뒤 평가한다.

<a id="mission-01"></a>
**MISSION-01 — 실린더·STRING.**
jog·해제 HOLD·시간 PWM을 지원하지만 실제 끝단/하중 보장이 아니다. 방향·전원 재인가·중단/torque 해제 검증이 남아 있다.

<a id="clegg-01"></a>
**CLEGG-01 — Nano·ADXL375.**
무선 원본·별도 파형·조건부 Rover context를 지원한다. 실제 반복 타격·장착/clock·접촉점·CIV/CBR·지속 무선은 미검증이다.

<a id="jumper-01"></a>
**JUMPER-01 — Scout v12.4.**
두 보드 설치/readback과 실제 점프 원본은 보존했다. 동시 수신·전원/단절·하중·독립 궤적/접촉/정지 위치 검증은 미완료다.

<a id="field-01"></a>
**FIELD-01 — Wi-Fi·복구.**
field service와 프로필 재연결을 유지한다. 최초 연습 단절 원인·모든 packet 고착 복구·거리/가림/지속 주행 신뢰성은 미확정이다.

<a id="video-01"></a>
**VIDEO-01 — 독립 영상 기록.**
H.264 TS·분할·fsync·누락 표시를 지원한다. 실제 카메라/AP 단절·장시간·정전 후 마지막 자료 보존은 미검증이다.

<a id="ops-01"></a>
**OPS-01 — 파일·설치 식별.**
최종 소스와 역사적 설치 근거를 구분한다. 재개 전 실제 파일/보드·clock·service 상태를 확인해야 하며 보관 시 신규 설치 성공을 추정하지 않는다.

<a id="replay-01"></a>
**REPLAY-01 — 구형 replay.**
empty/one-row 문제를 자료 삭제로 해결했다고 주장하지 않는다. 재사용하면 당시 설정/metadata와 짧은 입력을 별도로 확인한다.

<a id="field-02"></a>
**FIELD-02 — AX210 채택.**
해당 커널용 모듈을 사용한다. stock 대비 같은 조건 비교·10 m·반복 부팅/복구 검증은 미완료다.

<a id="map-01"></a>
**MAP-01 — 공통 지도.**
rigid XY 등록·frame 분리·추가 전용 journal을 지원한다. fit residual은 정확도가 아니며 실측 기준/검증점·사건 label·불확도 확인이 남아 있다.
