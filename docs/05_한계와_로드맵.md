# 현재 상태·남은 일

2026-10-08 보존 기록을 압축했다. 구현·벤치·실차 검증을 구분하며 기존 task ID를 유지한다.
현재 순서: **SAFE-01 + IMU-01 → HW-01 → ODOM-02/03 및 FIELD-01**.
실행은 [README](../README.md), 근거 목록은 [data](../data/README.md).

<a id="safe-01"></a>
**SAFE-01 — 모터 오류·watchdog · 미완료.** 읽기/쓰기 실패, 시작 일부 실패, freeze/kill/bus 단절 때 모든 모터 정지 보장 필요.
근거: [모터](../rover/motors.py), [제어](../rover/dxl_control.py). 완료 조건: 오류 주입과 실기 중단 시험으로 정지 확인.

<a id="safe-02"></a>
**SAFE-02 — 조종권 · 미완료.** 복수 스테이션의 명령 소유권이 정의되지 않음.
근거: [링크](../rover/station_link.py). 완료 조건: 두 client·접속 해제·E-STOP에 결정적인 소유권 확인.

<a id="hw-01"></a>
**HW-01 — 실차 통합 · 실기 대기; SAFE-01·IMU-01 선행.** PDB 설계 완료 보고는 조립 검증이 아님. 바퀴·IMU·Pico·하중·정지/복구 확인 필요.
근거: [하드웨어](06_하드웨어.md), [PCB](electronics/PDB_Design_Handover.md). 완료 조건: 실차 구성과 원본 로그를 포함한 주행·정지·복구 결과 기록.

<a id="io-01"></a>
**IO-01 — pan 한계·배터리 기록 · 미완료; HW-01 필요.** pan ±270° 제한·원점 설정, 실제 pack 경고 기준, 배터리 로그 미완료.
근거: [설정](../rover/config.py). 완료 조건: 실물 케이블 여유/회전 제한·전압 경고·기록 검증.

<a id="odom-01"></a>
**ODOM-01 — 샘플 유효성·정지 판정 · 미완료.** Arduino stale/nonfinite와 timestamp reset, use_zupt 비활성 경로의 정확성 점검 필요.
근거: [IMU](../rover/imu_reader.py), [odometry](../rover/odometry.py). 완료 조건: 오래된/잘못된 입력과 reset·gap·ZUPT off에서 잘못된 적분 방지 확인.

<a id="odom-02"></a>
**ODOM-02 — 장착 보정·run metadata · 일부 구현·실기 대기.** BMI088 sidecar에 소스/설정이 있으나 replay가 모두 자동 복원하지 않음. 장착축·온도·시간 지연·noise 검증 필요.
근거: [보정](03_튜닝과_NIS.md), [로그](../logs/README.md). 완료 조건: 설치 센서의 실측 보정 근거와 현재 설정에 독립적인 과거 재생 확보.

<a id="imu-01"></a>
**IMU-01 — BMI088 · 구현·벤치 확인 / 통신 재발 미해결.** 400 Hz FIFO 통합 기록이 있으나 이후 잘못된 ID가 재발. 느슨한 보드 시험으로 장착축/회전 정확도는 미검증.
근거: [Jetson](11_jetson_bringup.md), [정지 측정](../data/bmi088_stationary_2026-10-08/REPORT.md). 완료 조건: 반복 startup·장착축/부호·full-load timing·포화·온도·독립 회전 시험 통과.

<a id="odom-03"></a>
**ODOM-03 — 독립 주행 정답 · 실기 대기; HW-01·ODOM-01/02 선행.** 기존 줄자 기록은 튜닝에 사용됨. 명령 각도·경로 폐합만으로 정확도 평가 불가.
근거: [정답 범위](../logs/README.md). 완료 조건: 새 XY/heading 실측·오차/불확도 기록. 직진 ±5 cm와 합의한 각도/배치 기준 검증.

<a id="est-01"></a>
**EST-01 — 강건한 융합 · 조건부; ODOM-03 이후.** wheel yaw·gating·적응 noise·공개 위치 불확도는 독립 결과가 뒷받침할 때 평가.
근거: [과거 비교](../data/README.md). 완료 조건: 분리된 검증 데이터에서 baseline 대비 개선 확인.
